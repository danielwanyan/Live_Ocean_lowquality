## Task

Check all 19 live-room low-quality categories independently and in category_id order.
Use all Ocean segments, not a reduced sample.
Use Comment Interaction only as summary-derived interaction context.
Use Pearl product titles/images only where the compact rules allow them; never use Pearl material for a forbidden category.
Apply the compact rules and supplied v3 boundary contract before every decision.
For every fact name listed in boundary_output_schema_json.required_facts, output one fact object using the exact name and allowed source labels.
For every category_id from 1 through 19 in order, output one final_results object using the exact category name from the compact rules.

Category 7 remains an interruption or layer with at least 80% occlusion of the live screen. A still frame alone is not a Category 7 low-quality hit.

Category 10 evidence contract
Category 10 explicit_generated_content_evidence_found must come from a live Segment frame, ASR, or visible-text source.
Category 10 independently requires bound_product_evidence_found from a Pearl product title or image source.
Category 10 generated_product_material_mismatch_found must compare the live generated content with the bound product; Pearl-only evidence cannot hit Category 10.
Category 10 requires at least two distinct trusted sources across its required facts.

Decision precedence
1) If a category's required judging channel or material is absent, return unable_to_judge.
2) If the required judging channel is present but valid evidence is weak or below threshold, return no_hit.
3) If the category is disabled or evidence exists only in a forbidden source, return no_hit; this overrides the missing-material rule.

For every hit, evidence must be an array of concise Chinese objects. Each object must contain nonblank source, quote_or_visual_detail, and reason.
For no_hit and unable_to_judge, evidence may be empty, but judge_reason must explain the decision.
