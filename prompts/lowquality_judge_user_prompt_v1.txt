## Task

Check all 19 live-room low-quality categories independently.

Use all Ocean segments, not a 5-segment sample.
Use Comment Interaction only for the summary-derived interaction context.
Use Pearl products only according to product-image permission rules.

For every hit, provide evidence as an array of concise Chinese evidence objects. Each evidence object must include source, quote_or_visual_detail, and reason.

For no_hit and unable_to_judge, evidence may be empty, but judge_reason must explain why the category did not hit or could not be judged from available materials.
